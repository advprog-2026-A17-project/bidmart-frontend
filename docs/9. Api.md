# API — Modul 6 (Frontend)

Frontend memanggil **gateway** (`VITE_API_BASE_URL` atau same-origin). Implementasi: `src/config/api.ts`, hooks di `src/hooks/`, halaman di `src/pages/`.

## Autentikasi (modul 1)

`POST /api/v1/auth/login`, `register`, `refresh`, `logout`, `oauth/login`, `2fa/*`, `profile`, `sessions`

## Katalog (modul 2)

`GET /api/v1/catalogue/listings/search`, `GET/POST/PUT` listings, `publish`, `deactivate`, `cancel`

## Lelang (modul 3)

`POST /api/v1/listings` (buka sesi), `POST /api/v1/listings/{id}/bids`, `GET` bids, `POST .../close`

## Dompet (modul 4)

`GET /api/v1/wallet/{userId}`, top-up intent, withdraw

## Order & notifikasi (modul 5)

`GET /api/v1/orders`, `GET /api/v1/notifications`, dispute endpoints

## Realtime

SockJS + STOMP ke `/ws/notifications` — lihat [11. Keamanan stomp.md](../../bidmart-order-and-notification-service/docs/11. Keamanan stomp.md)
