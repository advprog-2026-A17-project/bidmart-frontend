# Profiling Report (Lighthouse)

Frontend performance evidence uses **Google Lighthouse** (navigation mode), not JVM/Rust CPU flame graphs.

## Artifacts

| File | Role |
|------|------|

## How to reproduce

```bash
# Stack running: docker compose up (frontend on :5173)
npx lighthouse http://localhost:5173 \
  --output html,json \
  --output-path ./artifacts/lighthouse-report.report \
  --chrome-flags="--headless"
```

Baseline capture (checkout pre-optimization tag if available):

```bash
npx lighthouse http://localhost:5173 \
  --output json \
  --output-path ./artifacts/lighthouse-before \
  --chrome-flags="--headless"
# Rename/copy to artifacts/lighthouse-before.json per team convention
```
