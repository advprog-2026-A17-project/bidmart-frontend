## Secure coding

- Tokens via `AuthContext`; no JWT in URL query strings.
- Production builds use gateway HTTPS; `VITE_*` only for public OAuth client id.
- STOMP CONNECT: `Authorization: Bearer <access_token>`.
- Admin routes: client-side guard + server RBAC (defense in depth).
- Service worker [`public/push-sw.js`](../public/push-sw.js) scoped to app origin.
