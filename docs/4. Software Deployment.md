# Software Deployment

## CI/CD

Workflow: [`.github/workflows/ci.yml`](../.github/workflows/ci.yml)

| Job | Trigger | Steps |
|-----|---------|-------|
| `test` | push / PR | `npm ci`, `npm run lint`, `npm test`, `npm run build` |
| `e2e-nightly` | cron + `workflow_dispatch` | Playwright against staging URL; uploads `playwright-html-report` |
| `sonarcloud` | after `test` | Sonar scan when `SONAR_TOKEN` secret present |

Bukti CI: `docs/evidence/ci-workflow-success-2026-05-21.png`

## Local dev (Docker backend + Vite on host)

| Item | Detail |
|------|--------|
| Backend | `docker compose up` in [`bidmart-infrastructure`](../../bidmart-infrastructure) |
| Frontend | `npm run dev` in this repo → http://localhost:5173 |
| API | Vite proxies `/api` and `/ws` to `http://localhost:8000` when `VITE_API_BASE_URL` is empty |
| Env | Copy [`.env.example`](../.env.example) → `.env` |

Frontend is **not** a Docker Compose service in local dev (avoids `node_modules` volume issues and OOM on `npm ci` in container).

## Heroku / static hosting

- `heroku-postbuild`: `npm run build`
- `npm start`: `serve -s dist` (see `package.json`)
- Platform deploy notes: [bidmart-infrastructure/docs/DEPLOYMENT.md](../../bidmart-infrastructure/docs/DEPLOYMENT.md)

## Lighthouse in release evidence

Run locally with full stack:

```bash
npx lighthouse http://localhost:5173 \
  --output html,json \
  --output-path ./artifacts/lighthouse-report.report
```

Commit or attach artifacts per [12. Before after perf.md](../../bidmart-infrastructure/docs/12. Before after perf.md).

## Rollback (frontend-only)

Static assets roll back by redeploying previous `dist/` build or Heroku release rollback — coordinated with gateway rollback per [14. Deployment rollback.md](../../bidmart-infrastructure/docs/14. Deployment rollback.md).

## Metrics

Frontend does not expose `/actuator/prometheus`. Platform metrics: gateway + service jobs in Grafana; UX metrics via Lighthouse + optional Microsoft Clarity.
