# Spesifikasi — Modul 6 (Frontend)

## Tanggung jawab

Antarmuka pengguna untuk seluruh alur modul 1–5: auth, jual/beli lelang, dompet, order, admin, notifikasi live.

## Fitur UI

- Login, registrasi, profil, admin RBAC
- Browse & search katalog, detail listing
- Seller: buat listing, publish, kelola
- Buyer: bid, proxy bid, live updates
- Dompet: saldo, top-up Midtrans sandbox
- Order & dispute
- Notifikasi in-app + STOMP
- E2E Playwright (auth, auction, wallet, concurrency, dispute)

## Non-scope

Logika bisnis server; hanya konsumen API gateway.
